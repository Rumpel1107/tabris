# AGENTS.md

Entry point for any AI agent (or human) working on this repository. This file holds no rules
of its own — it names where they live, so there is nothing here to drift out of sync.

- **How this project is run** — setup, tests, code conventions, architecture patterns and documentation upkeep: [`CONTRIBUTING.md`](CONTRIBUTING.md). Read it before writing anything.
- **What the project is** — goals, decisions and roadmap: [`PLAN.md`](PLAN.md).
- **Collaboration style** — how the maintainer works with an agent: the `/method` skill's `collaboration.md`, when that skill is available. It is personal, lives outside this repository, and nothing in it is required to contribute here.
